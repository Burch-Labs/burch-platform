⚡ 3-STEP DEPLOYMENT (25 minutes)

STEP 1: Deploy API to Vercel (10 minutes)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Go to: https://vercel.com/new
2. Connect GitHub → Select burch-platform
3. Set root directory: apps/web
4. Add environment variables:
   - DATABASE_URL = [PostgreSQL on Supabase]
   - NEXTAUTH_SECRET = [run: openssl rand -base64 32]
   - NEXTAUTH_URL = https://api-burch-xxxxx.vercel.app
   - MPESA_CONSUMER_KEY = [your key]
   - MPESA_CONSUMER_SECRET = [your secret]
   - MPESA_PASSKEY = [your passkey]
   - MPESA_SHORTCODE = 174379
   - FLUTTERWAVE_SECRET_KEY = [your key]
   - FLUTTERWAVE_SECRET_HASH = [your hash]
   - STRIPE_SECRET_KEY = sk_test_[your key]

5. Click Deploy
6. Note your API URL: https://burch-api-xxxxx.vercel.app

RESULT: ✅ API Ready at https://burch-api-xxxxx.vercel.app

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 2: Prepare Files for Hostgator (10 minutes)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Option A: Automated (Recommended)
──────────────────────────────────

1. Open terminal in project root
2. Get Hostgator FTP credentials:
   - Log in to cPanel: https://cpanel.hostgator.com
   - Go to: Files → FTP Accounts
   - Note:
     * FTP Host: ftp.yourdomain.com
     * Username: cpaneluser
     * Password: cpanelpass

3. Run deployment script:
   ./scripts/deploy-hostgator.sh ftp.yourdomain.com cpaneluser cpanelpass

4. Wait for upload to complete (5-10 minutes)
5. Script automatically:
   ✅ Builds Next.js
   ✅ Prepares files
   ✅ Uploads to Hostgator
   ✅ Configures .htaccess
   ✅ Sets environment variables

Option B: Manual Upload
───────────────────────

1. Build locally:
   cd apps/web
   npm run build

2. Download FTP client:
   - Windows: FileZilla (https://filezilla-project.org)
   - Mac: Cyberduck (https://cyberduck.io)
   - Linux: FileZilla or command line (lftp)

3. Connect to Hostgator FTP:
   - Host: ftp.yourdomain.com
   - Username: cpaneluser
   - Password: cpanelpass
   - Port: 21

4. Upload files to public_html:
   - Navigate to: apps/web/.next locally
   - Drag to: public_html on Hostgator

5. Upload .htaccess from repo root:
   - File: .htaccess.hostgator
   - Rename to: .htaccess
   - Upload to: public_html

6. Create .env.local with:
   NEXT_PUBLIC_API_URL=https://api-burch-xxxxx.vercel.app
   Upload to: public_html

RESULT: ✅ Files Ready on Hostgator

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Enable HTTPS:
   - cPanel → SSL/TLS → AutoSSL
   - Click: Check and install
   - Wait 5-10 minutes

2. Test your site:
   - Homepage: https://yourdomain.com
   - Checkout: https://yourdomain.com/checkout

3. Test payment flow:
   - Fill guest details
   - Select M-Pesa, Flutterwave, or Stripe
   - Click "Complete Booking"
   - Should redirect to Vercel API
   - Payment should process

================================================================================
⚠️ LIMITATION EXPLAINED
================================================================================

Why Hostgator alone doesn't work:
- Hostgator shared hosting runs Apache web server only
- No Node.js runtime environment
- Can't run Express.js API endpoints
- Can't receive payment webhooks
- Can only serve static HTML files

Solution: Hybrid Approach
- Hostgator serves static frontend files
- Vercel runs the payment API backend
- Frontend makes HTTP requests to Vercel
- CORS allows cross-origin requests
- Results: Full functionality at minimal cost!

Alternative: Hostgator VPS
- Upgrade to VPS ($20+/month)
- Request Node.js installation
- Deploy full Next.js app
- Everything runs on Hostgator
- Higher cost but more control

📞 SUPPORT & TROUBLESHOOTING
================================================================================

Files Not Showing on Hostgator:
→ Check .htaccess is in public_html
→ Verify upload completed
→ Refresh browser cache (Ctrl+Shift+Del)

Payment Not Processing:
→ Check Vercel API is running: https://api-url/api/health
→ Verify NEXT_PUBLIC_API_URL in .env.local
→ Check browser console (F12) for errors
→ Verify payment provider keys in Vercel

404 Errors:
→ .htaccess missing or misconfigured
→ .next folder not uploaded completely
→ Wrong permissions on files

SSL Certificate Issues:
→ Wait 5-10 minutes for AutoSSL to complete
→ Use "Check and install" in cPanel

FTP Connection Failed:
→ Verify username/password in cPanel FTP Accounts
→ Try different FTP port (990, 2121)
→ Check if IP whitelisted (Hostgator support)

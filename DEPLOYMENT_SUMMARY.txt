🔗 KEY API ENDPOINTS
================================================================================

POST /api/payments/initiate
→ Create new payment
→ Body: {bookingId, amount, currency, paymentMethod, customerName, etc}
→ Returns: {status, method, paymentLink or clientSecret}

GET /api/payments/verify?bookingId=xxx
→ Check payment status
→ Returns: {status, amount, currency, provider, createdAt}

POST /api/payments/mpesa/callback
→ M-Pesa webhook (auto-called by Safaricom)

GET /api/payments/flutterwave/callback
→ Flutterwave redirect (user redirected after payment)

GET /api/health
→ Health check
→ Returns: {"status":"ok"}

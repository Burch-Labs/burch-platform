## 📋 How to Request Updates

### **Step 1: Draft New Copy**
Create compelling alternative messaging. Example:
```

Proposed: "Discover Extraordinary Experiences"
Why: More action-oriented, emphasizes discovery
```

### **Step 2: Send to Developer Agent**
```
"Developer, update the hero headline to: 'Discover Extraordinary Experiences'"
```

### **Step 3: Verify with CEO**
```
"CEO, I've updated the messaging on the landing page to emphasize premium positioning"
```

## 🎨 Tone & Voice Guidelines

✅ **DO**:
- Be aspirational and premium
- Use action verbs (Discover, Experience, Explore)
- Keep it concise and punchy
- Emphasize exclusivity and quality
- Use benefit-focused language

❌ **DON'T**:
- Be too corporate or stiff
- Use complex jargon
- Over-promise or exaggerate
- Be too casual for premium positioning
